# 双语 · 注音歌词（bilingual-ruby-lyrics）

一个 [Folia](https://github.com/chthollyphile/folia-major) 模组，做两件事：

- **双语配对**：歌词里同一时间点的原文和译文配成一对，一起显示；可以选主要显示原文还是译文。
- **逐字注音**：读取 MP3 里内嵌的 TimeTag/NicoKara Ruby 歌词（`[MM:SS:CC]` 逐字时间 + `@RubyN` 注音），在歌词上方显示注音，并随演唱逐字变色。日语汉字的振假名、韩语的罗马音、「運命」读作「さだめ」这类特殊读法都可以。

![预览](bilingual-ruby-lyrics/preview.png)

## 安装

把 `bilingual-ruby-lyrics` 文件夹（或模组市场下载的 zip）拖进 Folia 的模组面板，启用后在显示模式里选「双语 · 注音歌词」。

需要 Folia 0.7.12。模组用到了 Folia 的内部接口，所以钉死了宿主版本；Folia 更新后需要等模组发布对应的新版本。

## 设置

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 主要显示 | 原文 | 大字显示原文还是译文 |
| 双语显示 | 开 | 在主要语言下面显示另一种语言 |
| 显示注音 | 开 | 显示内嵌歌词里的注音 |
| 海报歌词（实验性） | 关 | 在展开的海报卡片上也使用本模组的歌词，见下文 |

播放器面板里有同样的开关，命令面板里可以搜“双语”“注音”切换。

## 带注音的歌词从哪来

模组只负责读取和显示。歌词需要事先写进 MP3 的 ID3 标签：默认的歌词帧放普通双语 LRC（任何播放器都能读），另一个描述为 `TimeTag-Ruby` 的歌词帧放带逐字时间和 `@Ruby` 的版本。

可以用 [lyric-timing-kit](https://github.com/Rizumu85/lyric-timing-kit) 自动生成并写入，也可以用任何能导出 NicoKara/TimeTag 格式的打轴软件。

没有内嵌 Ruby 歌词的歌，模组照常显示 Folia 自己取到的歌词，双语配对仍然有效，只是没有注音。

## 权限与行为说明

| 项目 | 用途 |
| --- | --- |
| `playback.control` | 点击某一行歌词时跳到那一句 |
| `ui.stage` | 注册显示模式和舞台图层 |
| `folium.internals`（钉死 `folia: "=0.7.12"`） | 读取当前歌曲和歌词状态（`stores.playback`、`stores.lyricSettings`），把解析出的注音歌词交给宿主的歌词状态 |

模组会做的事：

- 读取正在播放的本地 MP3 的 ID3 标签头部（只读，最多 16 MB），取出其中的歌词帧。绝对路径由 `main.cjs` 读取；通过文件夹授权添加的歌曲用宿主已保存的目录句柄读取。
- 只读访问宿主的 IndexedDB（`KineticPlayerDB` 的 `local_music` 和目录句柄记录），用来找到当前歌曲的文件。
- 不联网，不启动进程，不写任何文件。

### 关于“海报歌词”

这个选项默认关闭。Folia 目前没有为海报卡片上的歌词提供注册接口，所以开启后，模组会直接修改宿主页面：往页面里加一个样式表，在当前展开的海报卡片里加一个元素（用 Shadow DOM 隔离）并隐藏卡片原有的歌词，同时监听页面变化来发现新出现的卡片。关闭选项或停用模组时，这些改动会全部撤销。

这不符合“模组不操作自己容器以外的宿主页面”的一般约定，因此做成了需要用户主动开启的实验性选项。如果 Folia 之后提供了海报歌词的正式接口，会改用正式接口。
