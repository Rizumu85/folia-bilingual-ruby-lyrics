# 双语 · 注音歌词（bilingual-ruby-lyrics）

一个 [Folia](https://github.com/chthollyphile/folia-major) 模组，做三件事：

- **双语配对**：歌词里同一时间点的原文和译文配成一对，一起显示；可以选主要显示原文还是译文。
- **逐字注音**：读取音乐文件里内嵌的 TimeTag/NicoKara Ruby 歌词（`[MM:SS:CC]` 逐字时间 + `@RubyN` 注音），在歌词上方显示注音，并随演唱逐字变色。日语汉字的振假名、韩语的罗马音、「運命」读作「さだめ」这类特殊读法都可以。
- **整句罗马音**：按内嵌的注音把每一句拼成罗马音，交给 Folia 的罗马音字幕。因为用的是歌词里已经核对过的读法，不查词典，所以特殊读法也会拼对。

![预览](bilingual-ruby-lyrics/preview.png)

## 安装

把 `bilingual-ruby-lyrics` 文件夹（或模组市场下载的 zip）拖进 Folia 的模组面板，启用后在显示模式里选「双语 · 注音歌词」。

需要 Folia 0.7.12 到 0.7.18。模组用到了 Folia 的内部接口，所以只声明逐个核对过的宿主版本；Folia 更新后需要等模组发布对应的新版本。

## 设置

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 主要显示 | 原文 | 大字显示原文还是译文 |
| 显示注音 | 开 | 显示内嵌歌词里的注音 |
| 注音字幕条 | 关 | 用 Folia 自带的显示模式时，在画面底部或顶部加一条带注音的当前歌词 |
| 逐字跳亮 | 关 | 显示模式和海报歌词里，每个字到点时整个亮起（一字一跳），而不是从左到右扫过；光晕等其余效果不变 |
| 海报歌词（实验性） | 关 | 在展开的海报卡片上也使用本模组的歌词，见下文 |

播放器面板里有同样的开关。命令面板里有两个命令，执行后会弹出提示说明当前状态：“切换注音显示与否”“切换注音字幕条（底部 → 顶部 → 关）”。

### 注音字幕条

Folia 自带的显示模式不画注音。打开这个选项后，使用那些模式时画面上会多一条字幕：当前这句歌词加上注音，随演唱逐字变色（正在唱的字是主题的强调色）。可以放在底部（在 Folia 自己的字幕上方）或顶部。只对有内嵌注音的歌生效；用本模组自己的显示模式时不出现。

字幕条打开时，Folia 自己画在显示模式下面的罗马音和译文也会换成字幕条的样子（不透明、同样的阴影、去掉后面那团模糊的底），免得两种风格挨在一起。显示哪几行、字号、字体和颜色仍然是 Folia 的。字幕条关掉后，Folia 的字幕恢复原样。

### 译文和罗马音显示与否

译文和罗马音都没有单独的开关，完全跟随 Folia 自己的字幕设置：选“翻译”显示译文，选“罗马音”显示罗马音，选“罗马音与翻译双行显示”两行都显示，关闭字幕翻译就都不显示。Folia 自带的显示模式、本模组的显示模式和海报歌词都按这一个设置来。「主要显示」选译文时，这个设置管的是下面那行原文显示与否。罗马音那一行，有内嵌注音的歌是本模组拼出来的；其他歌用 Folia 自己取到的罗马音。

罗马音是在播放时现算的，不写进音乐文件，所以同一个 MP3 放到别的播放器或卡拉OK软件里不会多出一行。分词用的是系统自带的日语分词，假名写的词有时会被拆得比较碎（例如 `haji mari`），不影响读音；助词は、へ、を按实际发音写成 wa、e、o。

### 样式跟随 Folia

模组不带自己的样式设置，歌词长什么样都在 Folia 里改：主题颜色、歌词字体和字重、情绪词配色（和海报歌词的“关键字着色”开关）、歌词字号倍率、字幕字号倍率、字幕主题和翻译字体、歌词层不透明度。副歌行用强调色和更大的光晕，按 Folia 识别出的副歌来；系统开了“减少动态效果”时不画模糊和光晕。

显示模式和海报歌词是同一种画法，照的是 Folia 自己海报歌词的样子：逐字扫过的填充、字后面升起再淡出的光晕、前后两句缩小并虚化。这些数值在 Folia 里不是设置项，模组用的是和它相同的一组数。

注音字幕条不用这套画法，也不跟 Folia 的字幕设置：它要叠在 Folia 的各个显示模式（以及别的模组做的显示模式）上面，这些模式画法差别很大，共同点只有主题色。所以字幕条固定不透明、固定大小，只用主题的三种颜色，不加光效：还没唱的字用次要色，唱过的用歌词色，正在唱的用强调色。字周围有一圈主题背景色的柔和阴影；播放页用了透明背景或系统毛玻璃时，改成不带模糊的硬阴影（同一行字垫在下面，往右、往下各偏约 3px，是实心的一块，便于辨认），免得晕影在实际画面上显脏。

## 带注音的歌词从哪来

模组只负责读取和显示。歌词需要事先写进音乐文件的标签：默认的歌词标签放普通双语 LRC（任何播放器都能读），另一个标签放带逐字时间和 `@Ruby` 的版本。

模组按文件里实际的标签种类来读，不看扩展名，所以 Folia 能播放的格式基本都支持：

| 标签种类 | 格式 | 普通歌词 | 带注音的歌词 |
| --- | --- | --- | --- |
| ID3v2 | MP3、AAC、TTA，以及 WAV、AIFF 里的 ID3 块 | 默认的 `USLT` 帧 | 描述为 `TimeTag-Ruby` 的 `USLT` 帧 |
| Vorbis 注释 | FLAC、OGG、Opus | `LYRICS` | `RUBY_LYRICS` |
| MP4 | M4A、ALAC | `©lyr` | `----:com.apple.iTunes:RUBY_LYRICS` |
| APEv2 | APE、WavPack | `Lyrics` | `RUBY_LYRICS` |
| ASF | WMA | `WM/Lyrics` | `RUBY_LYRICS` |

带注音的歌词直接放在普通歌词的那个标签里也能读到。CAF 没有通用的歌词标签，不支持。

可以用 [lyric-timing-kit](https://github.com/Rizumu85/lyric-timing-kit) 自动生成并写入，也可以用任何能导出 NicoKara/TimeTag 格式的打轴软件生成，再按下表写进文件的标签。

没有内嵌 Ruby 歌词的歌，模组照常显示 Folia 自己取到的歌词，双语配对仍然有效，只是没有注音。

## 权限与行为说明

| 项目 | 用途 |
| --- | --- |
| `playback.control` | 点击某一行歌词时跳到那一句 |
| `ui.stage` | 注册显示模式和舞台图层 |
| `folium.internals`（`folia: ">=0.7.12 <=0.7.18"`） | 读取当前歌曲和歌词状态（`stores.playback`、`stores.lyricSettings`），把解析出的注音歌词交给宿主的歌词状态；读取当前显示模式和“关键字着色”开关（`stores.visualizerSettings`），用来决定注音字幕条是否出现、歌词里的情绪词要不要上色 |

模组会做的事：

- 读取正在播放的本地音乐文件的标签区（只读，每块最多 16 MB），取出其中的歌词；只读文件头和标签，不读音频数据。绝对路径由 `main.cjs` 读取；通过文件夹授权添加的歌曲用宿主已保存的目录句柄读取。
- 只读访问宿主的 IndexedDB（`KineticPlayerDB` 的 `local_music` 和目录句柄记录），用来找到当前歌曲的文件。
- 只读访问宿主的四项本地设置（`localStorage`），都是 Folia 没有交给模组的状态：`hide_player_translation_subtitle`（底部字幕层是否隐藏，隐藏时注音字幕条贴到最底下）；`subtitle_content_mode`（Folia 把“罗马音与翻译双行显示”报告给模组时会说成“翻译”，要靠这一项才能分辨）；`transparent_player_background` 和 `enable_player_page_native_blur`（播放页是透明背景或系统毛玻璃时，注音字幕条改用不带模糊的硬阴影，因为主题背景色和实际画面对不上，宽的晕影会显脏）。
- 注音字幕条打开期间，往宿主页面注入一段样式（通过 `folium.registries.styles`），改 Folia 自己字幕行的不透明度和阴影、隐藏字幕后面的模糊底。Folia 没有为字幕提供公开的样式接口，这段样式是按它字幕层现有的标记（`data-subtitle-track`）写的，不属于稳定接口：Folia 以后改了结构，这段样式会不再生效，字幕回到原样，不会出错。字幕条关掉或模组停用时样式撤掉。
- 不联网，不启动进程，不写任何文件。

### 关于“海报歌词”

这个选项默认关闭。开启后，卡片上的歌词沿用 Folia 自己海报歌词的样子（逐字扫过的填充、字后面的光晕、前后两句缩小并虚化、副歌用强调色），只是多了注音。Folia 目前没有为海报卡片上的歌词提供注册接口，所以开启后，模组会直接修改宿主页面：往页面里加一个样式表，在当前展开的海报卡片里加一个元素（用 Shadow DOM 隔离）并隐藏卡片原有的歌词，同时监听页面变化来发现新出现的卡片。关闭选项或停用模组时，这些改动会全部撤销。

这不符合“模组不操作自己容器以外的宿主页面”的一般约定，因此做成了需要用户主动开启的实验性选项。如果 Folia 之后提供了海报歌词的正式接口，会改用正式接口。

## 开发

源码在 `src/`，Folia 加载的 `bilingual-ruby-lyrics/client.mjs` 和 `main.cjs` 是由它们生成的单文件，不要直接改。做成单文件是因为 Folia 重载模组时只重新加载入口文件，入口再用相对路径引入的其他文件会沿用旧的，更新后不重启就会新旧代码混用。

```text
node tools/build.mjs                # 由 src/ 生成 Folia 加载的两个文件
node --test test/mod.test.mjs       # 模组逻辑的测试，歌词都是自造的例子
python tools/make_preview.py        # 重新生成介绍图
```
